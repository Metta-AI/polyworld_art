# Astronaut sources

Original astronaut geometry, metadata and model previews were created for
Polyworld by Softmax / Polyworld contributors with Codex on 2026-10-06.
They use the repository's CC0-1.0 dedication in the root LICENSE.

The generated concept was made with the built-in image generator from the
user's three visual references. The reference bitmaps are not bundled or
relicensed. Their roles and digests are recorded in provenance.json.

The model reuses the current project-generated Chargen body and canonical rig.
Animation preview poses use the Quaternius Universal Animation Library
Standard, under its existing CC0 license notice at
animations/quaternius/universal_standard/README.txt.

Authoring and validation scripts use the repository's MIT LICENSE-CODE.
