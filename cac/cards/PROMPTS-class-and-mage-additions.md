# October 14, 2026 card additions

Six standalone illustrations generated with the built-in image generation tool on 2026-10-14. These complete the 36-card base set: three class level-up trinkets and three new Mage cards. Existing artwork is preserved. No image inputs were sent to the tool; existing Sniper, Footsoldier and Bubble Shield illustrations were visually inspected to guide the written style descriptions.

Final PNGs are copied without edits into `art/`, using the card-name slug. Original project artwork follows the repository's CC0-1.0 dedication.
