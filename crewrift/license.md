# CrewRift ship artwork

Josh Grafton authored the original ship model and embedded textures for
Softmax Inc, the copyright owner. The user confirmed the creator and ownership
on 2026-10-07. This Softmax-owned contribution uses the repository's existing
CC0-1.0 dedication in the root LICENSE.

The runtime GLB is copied without modification. The navigation triangles and
station positions were extracted from the authored Blender guide by
polyworld/tools/import_crewrift.py. See source.json for source paths, the model
hash, and runtime transformations.

The large editable Blender source, intermediate model exports, screenshots,
probe scenes, and recorded replays remain local and are not included here.
