# October 2026 card additions

Nine standalone illustrations generated with the built-in image generation tool on 2026-10-09. These fill the missing illustrations in the 30-card base set. Existing artwork is preserved. No input images were sent to the tool; the existing Sniper, Footsoldier and Bubble Shield illustrations were visually inspected to guide the written style descriptions.

Final PNGs are copied without edits into `art/`, using the card-name slug. Original project artwork follows the repository's CC0-1.0 dedication.
