# Generated particle textures

Created with the built-in image_gen tool. The PNG files are original generated grayscale artwork on black backgrounds. The fragment shader thresholds near-black texels and tints each system before additive blending.

## ribbon.png

```text
Use case: stylized-concept
Asset type: single grayscale VFX particle sprite for an additive GPU game renderer, square 1024x1024 texture.
Primary request: one long tapered magical flame ribbon, vertical with a bright pointed root near bottom center and a flowing curved wispy tail towards top center. Hand-painted stylized game FX with three crisp curving blade-like tongues and restrained soft glow. White at root, pale gray ribbons, gray feathered tail. The ribbon occupies central 60% width and 80% height.
Scene/backdrop: perfectly solid pure black RGB 0,0,0.
Color palette: grayscale only so it can be tinted in the shader.
Constraints: one isolated sprite, ample black margin on all sides, all glow fades completely to pure black before edges. No scenery, no stars, no text, no border, no checkerboard, no watermark. This is a reusable sprite, not a complete effect scene.
```
