# Heartleaf logo

`heartleaf_logo.png` is the user's supplied copy of the existing generated
Heartleaf logo, selected for the game on 2026-09-24. It is preserved byte for
byte from the supplied PNG, including its transparency.

The underlying project-generated logo is covered by the Softmax CC0-1.0
dedication in the root LICENSE and its 2026-09-21 owner confirmation that
project-generated logos are AI-generated artwork. The existing copy in
`polyworld_data/themes/heartleaf/heartleaf_logo.png` was inspected to establish
the artwork's source. That existing file has SHA-256
`75c6ba3567704af087974f1eced25f511eec843d76895a166e9901ee14ae0807`.
The supplied copy has small pixel and encoding differences from that file.
Its exact SHA-256 and size are recorded in `licenses/assets.json`.

Only this logo is restored from the legacy theme. No Unity assets or old
character portraits are included.
