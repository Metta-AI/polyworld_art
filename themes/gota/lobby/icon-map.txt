Three font sizes at the 1672 x 941 reference canvas

48 px - Screen titles: BATTLE SETUP and MULTIPLAYER.
28 px - Section headings.
20 px - All other text: brand, subtitle, labels, values, buttons, badges,
        slot numbers, helper text, table headers, room names, pagination.

Fonts: fonts/Rubik-Regular.ttf and fonts/Rubik-Bold.ttf.
Use weight, color and spacing for emphasis, not additional font sizes.

Draw toggle tracks, toggle thumbs, slot-number circles, panel frames,
fields and buttons as UI geometry. The map thumbnail is a map preview,
not an icon. The existing units.png has luminance-alpha (LA) storage,
which is valid transparent PNG artwork; other mapped icons use RGBA.
