# Heartleaf layer terrain materials

Creator: Softmax / Polyworld contributors, with Codex and built-in imagegen.
License: CC0-1.0, under the project artwork dedication in the repository LICENSE.
Date: 2026-09-25.

Nine original grass, golden earth and limestone materials were generated from
`terrain/heartleaf/layers/01-grass-and-paths.png` as the authorized style and color
reference. The project-generated reference is also CC0-1.0. A second imagegen
pass generated aligned physical height values from the repaired color atlas.

The terrain skill's Nim/Pixie tools repaired narrow color and height edge bands
at 1254 by 1254, then exported nine 256 by 256 pairs. No existing Unity or
restricted third-party assets were used. Prompts and exact input/output hashes
are recorded beside this notice.
